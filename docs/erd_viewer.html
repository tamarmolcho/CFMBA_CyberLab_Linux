📋 מילון ישויות ומבנה הטבלאות (Data Dictionary)

שם הישות (Entity) קשרים (Cardinality) מפתח ראשי (PK) מפתחות זרים (FK) תיאור תפקיד הישות במערכת
USER 1:N מול Environments, ActionLog user_id role_id משתמשי המערכת (Admin, Lecturer, Student). סיסמאות מוצפנות ב-scrypt ושיוך תפקידים.
ROLE 1:N מול User, N:M מול Permission role_id - קבוצות תפקידים וסמכויות במערכת (Admin, Lecturer, Student, Guest).
PERMISSION N:M מול Role permission_id - הרשאות גישה פרטניות למודולים (vms, terminal, import, surveillance, network, game).
ROLE_PERMISSION טבלת קשר N:M role_id, permission_id role_id, permission_id שיוך הרשאות מרובות לתפקידים.
HOST 1:N מול VirtualSystem host_id - השרת המארח (Kali Linux / Hypervisor), כתובת IP ומצב עבודה (Real / Demo).
VIRTUAL_SYSTEM 1:N מול Host, N:M מול Environment system_id host_id 21 מכונות המעבדה בצי: UUID, שם, מערכת הפעלה, RAM, מעבדים, כתובת IP וסטטוס.
ENVIRONMENT 1:N מול EnvironmentSystem, Run environment_id owner_user_id תרחישי מעבדה לימודיים (Scenarios) המאגדים קבוצות מכונות מאוחדות.
ENVIRONMENT_SYSTEM טבלת שיוך מכונה לתרחיש env_sys_id environment_id, system_id קביעת סדר הדלקה (Boot Order) ותפקיד המכונה בתרחיש (Attacker / Target).
ENVIRONMENT_RUN 1:N מול Environment run_id environment_id, started_by הפעלות מרוכזות של תרחישים (Batch Start) ומצב הרשת (NAT Network / Bridged).
ACTION_LOG 1:N מול User log_id user_id יומן ביקורת מאובטח (Audit Trail) של כל פעולות המעבדה, זמנים וקודי חזרה.
THREAT_DRILL_RESULT אימון מהירות תגובה drill_id - תוצאות אימון זיהוי איומי סייבר במילי-שניות הנשמרות ל-results.csv.
